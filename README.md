# Finans İmparatorluğu sürümleri

Bu depo, Windows'ta kurulu oyunun kendini güncellemesi için kullanılır. Oyun açılışta `latest.yml` dosyasına
bakar; yeni sürüm varsa kurulum dosyasını indirir ve bir sonraki açılışta kurar.

İlk kurulum için güncel kurulum dosyası: `latest.yml` içindeki `path` satırında yazan `.exe`.

Oyun imzasızdır; Windows ilk açılışta uyarı gösterebilir ("Ek bilgi" → "Yine de çalıştır").
